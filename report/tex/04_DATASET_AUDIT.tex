\section{1. Dataset Structure}

The perception and temporal world model pipeline uses the \textbf{KITTI Object Tracking} training benchmark:

\begin{itemize}[leftmargin=1.5em,itemsep=2pt]
\item \textbf{Images}: \texttt{training/\allowbreak{}image\_\allowbreak{}02/\allowbreak{}<seq>/\allowbreak{}<frame>.\allowbreak{}png} (\texttt{data\_\allowbreak{}tracking\_\allowbreak{}image\_\allowbreak{}2.\allowbreak{}zip}, \texttt{14.\allowbreak{}73 GiB}, \texttt{10 Hz} sequential RGB frames)
\item \textbf{Labels}: \texttt{training/\allowbreak{}label\_\allowbreak{}02/\allowbreak{}<seq>.\allowbreak{}txt} (\texttt{data\_\allowbreak{}tracking\_\allowbreak{}label\_\allowbreak{}2.\allowbreak{}zip}, \texttt{2.\allowbreak{}15 MiB}, 17-column format)
\item \textbf{Calibration}: \texttt{training/\allowbreak{}calib/\allowbreak{}<seq>.\allowbreak{}txt} (\texttt{data\_\allowbreak{}tracking\_\allowbreak{}calib.\allowbreak{}zip}, containing \texttt{P2} camera projection matrix for ground-plane ego transformation)
\end{itemize}

\section{2. Integrity Verification Protocol}

Implemented in \href{https://github.com/Heisnotanimposter/Totalcare\_autonomous\_driving\_Yolov5/blob/main/src/kitti\_prep.py}{src/kitti\_prep.py} (\texttt{audit\_\allowbreak{}images\_\allowbreak{}and\_\allowbreak{}labels}) and initially audited in \href{https://github.com/Heisnotanimposter/Totalcare\_autonomous\_driving\_Yolov5/blob/main/untitled63.py}{untitled63.py}:


\begin{enumerate}[leftmargin=1.8em,itemsep=2pt]
\item \textbf{Archive CRC \& Decode Check}:
\begin{itemize}[leftmargin=1.5em,itemsep=2pt]
\item \texttt{ZipFile.\allowbreak{}testzip()} verifies zero corrupt archive members.
\item \texttt{PIL.\allowbreak{}Image.\allowbreak{}verify()} checks image readability across all \texttt{8,\allowbreak{}008} training frames across \texttt{21} sequences (\texttt{0000}--\texttt{0020}).
\end{itemize}
\item \textbf{1:1 Image-Label Correspondence}:
\begin{itemize}[leftmargin=1.5em,itemsep=2pt]
\item Every sequence ID in \texttt{training/\allowbreak{}image\_\allowbreak{}02/\allowbreak{}} matches \texttt{training/\allowbreak{}label\_\allowbreak{}02/\allowbreak{}}.
\item Counts \texttt{missing\_\allowbreak{}image\_\allowbreak{}count}, \texttt{extra\_\allowbreak{}image\_\allowbreak{}count}, \texttt{duplicate\_\allowbreak{}image\_\allowbreak{}frame\_\allowbreak{}count}, and \texttt{label\_\allowbreak{}frame\_\allowbreak{}without\_\allowbreak{}image\_\allowbreak{}count}.
\item Frames with zero annotated objects (empty label frames) are retained as valid negative frames in YOLO export.
\end{itemize}
\item \textbf{Label Row Validation}:
\begin{itemize}[leftmargin=1.5em,itemsep=2pt]
\item Enforces 17 fields per row, finite numeric values, and \texttt{x2 > x1}, \texttt{y2 > y1}.
\end{itemize}
\item \textbf{Sequence-Scoped Track IDs}:
\begin{itemize}[leftmargin=1.5em,itemsep=2pt]
\item KITTI \texttt{track\_\allowbreak{}id} values reset per sequence and are always treated as composite \texttt{(sequence\_\allowbreak{}id,\allowbreak{} track\_\allowbreak{}id)}.
\end{itemize}
\item \textbf{DontCare \& Distractor Masking}:
\begin{itemize}[leftmargin=1.5em,itemsep=2pt]
\item Target classes: \texttt{Car}, \texttt{Pedestrian}, \texttt{Cyclist}.
\item Adjacent KITTI classes (\texttt{Van} for \texttt{Car}; \texttt{Person}, \texttt{Person\_\allowbreak{}sitting} for \texttt{Pedestrian}) and \texttt{DontCare} regions are masked with neutral pixel value \texttt{114} during YOLO export (\texttt{pixel\_\allowbreak{}mask\_\allowbreak{}policy = dontcare\_\allowbreak{}and\_\allowbreak{}distractors}), preventing false negative penalties against TrackEval distractor taxonomy.
\end{itemize}
\end{enumerate}
