# 시각화 명세: 시계열 자차 중심 World Model

[src/world_visualizer.py](file:///Users/seungwonlee/Documents/GitHub/Totalcare_autonomous_driving_Yolov5/src/world_visualizer.py)에 구현됨.

## 1. 좌우 분할 화면 레이아웃

- **전체 합성 해상도**: `1360 × 632` (`왼쪽: 720 × 540` | `오른쪽: 640 × 540` | `하단 텔레메트리 HUD: 1360 × 92`), 프레임 레이트 `10 Hz` (KITTI 원본 프레임 레이트와 동일).

### 왼쪽 패널 — 관측 세계 (Observed World)
카메라 프레임의 직접 관측 정보만 표시합니다:
- 원본 KITTI `image_02` RGB 프레임
- 클래스별 색상 2D 바운딩 박스 (`Car`, `Pedestrian`, `Cyclist`) 및 MobileSAM 인스턴스 폴리곤 마스크
- 클래스 라벨, 시퀀스 격리 Track ID (`#id`), 검출 신뢰도 (`0.00–1.00`)
- (`v4`) 도로(녹색)·비도로(자주색)·자차로(청록색) 반투명 마스킹, 좌/우 차선 2차 다항식 폴리라인, 객체별 `[LANE]`/`[RD]`/`[NON-RD]` 배지

### 오른쪽 패널 — 추정 세계 (Inferred World)
구조화된 자차 중심 조감도(BEV, `X: [-18m, +18m]`, `Y: [-10m, +52m]`):
1. **자차 (Ego Vehicle)**: 원점 `(0, 0)`에 고정된 삼각형 마커
2. **주변 객체**: 클래스별 BEV 점유 표식, Track ID, 전방 거리(`m`)
3. **상대 위치**: 자차 좌표계 기준 거리 원호 (`10m`–`50m`)
4. **이동 방향 및 보정 속도**: `P2` 캘리브레이션이 활성화되고 트랙 관측 횟수가 `>= 3`일 때만 화살표 및 `m/s` 라벨 표시
5. **예측 궤적**: `+0.5s`, `+1.0s`, `+1.5s`, `+2.0s` 칼만 예측 노드
6. **자차 계획 경로**: 전방 주행 회랑 (`±1.6m` 반폭, `0–35m` 구간)
7. **도로 구조**: 자차 회랑 정렬 차로 경계 및 `v4` 지각 도로 폴리곤·곡률 차선
8. **점유 / 장애물**: 실선 점유 영역 및 각도 폐색 음영(Shadow Cone)
9. **충돌 위험**: 충돌 구간 링(`CONFLICT +t_s`) 및 `Risk Indicator >= 0.45` 시 위험 강조 표시
10. **불확실성 시각화**: 미래 예측 노드별 `1σ` 야코비안 공분산 타원 및 HUD 세부 내역(`Det`, `Depth ±m`, `Track`, `Pred +2s ±m`)
11. **시간 상태 분리**: 지수 감쇠되는 `Past World` 과거 궤적 vs `Present World` 현재 박스 vs `Future World` 확률 타원
12. **공간 한계**: 자차 후방(`Y < 0`) 및 카메라 수평 화각 외부는 대각선 해칭과 `UNKNOWN (Outside Front Camera FOV)` 라벨로 명시

## 2. 정보 상태 인코딩

| 상태 | 시각적 인코딩 | 의미 |
|---|---|---|
| **Observed (관측)** | 채워진 BEV 마커 + 흰색 테두리; 왼쪽 패널 2D 박스 | 현재 프레임 전방 화각(FOV) 내 직접 검출 |
| **Inferred (추정)** | 속이 빈 윤곽선 `[INF]`, 속도 화살표, 미래 타원, 충돌 링 | 지면 투영 또는 칼만 운동학 기반 추정치 |
| **Occluded (폐색)** | 전경 차량 후방 어두운 각도 음영; 빈 Coasting 박스 | 시선 차단 또는 일시적 미검출 유지 (`<= 1.0s`) |
| **Unknown (미관측)** | 어두운 대각선 해칭 배경 (`Y < 0` 및 FOV 원뿔 외부) | 단일 전방 카메라로 관측 불가; 절대 임의 추정(Hallucination) 안 함 |

## 3. 5초 단계별 시연 타임라인 (`--staged-demo`)

| 시간 구간 | 프레임 (`10 Hz`) | 활성화 레이어 |
|---|---|---|
| **0.0–1.0초** | `0–9` | **원시 관측 (Raw Observation)**: 카메라 영상 + 자차 `(0,0)` + FOV / `Unknown` 초기화 |
| **1.0–2.0초** | `10–19` | **객체 인식 (Object Perception)**: + 2D BBox, 클래스, 신뢰도, Track ID, BEV 검출, 폐색 음영 |
| **2.0–3.0초** | `20–29` | **시계열 이해 (Temporal Understanding)**: + Past World 감쇠 궤적, 보정 속도 벡터 |
| **3.0–4.0초** | `30–39` | **미래 예측 (Future Prediction)**: + 다중 시점 궤적(`0.5s–2.0s`), `1σ` 공분산 타원, 자차 계획 경로 |
| **4.0–5.0초+** | `40+` | **위험도 평가 & Safety Shield**: + Risk Indicator 게이지, 충돌 구간, 권고형 Safety Shield 판단 |

전체 오버레이 모드(`--full-overlay`)는 `t = 0.0초`부터 모든 레이어를 동시에 렌더링합니다.
