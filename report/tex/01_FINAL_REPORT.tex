\section{2. 학습 과정 및 개선 이력 (\texttt{v1 Baseline $\rightarrow$ v2 Improved $\rightarrow$ v3 BEV Fixed})}

\subsection{2.1 모델 학습 설정 및 아키텍처 진화}
\begin{enumerate}[leftmargin=1.8em,itemsep=2pt]
\item \textbf{\texttt{v1} Baseline (\texttt{YOLOv8s @ 640px})}: \texttt{epochs=30}, \texttt{batch=16}, \texttt{129 layers /\allowbreak{} 11.\allowbreak{}14M params /\allowbreak{} 28.\allowbreak{}6 GFLOPs}.
\item \textbf{\texttt{v2} Improved (\texttt{YOLO11m @ 960px} + Rare-Class Oversampling + \texttt{MobileSAM})}:
\begin{itemize}[leftmargin=1.5em,itemsep=2pt]
\item 해상도를 \texttt{640 $\rightarrow$ 960}으로 상향하고 \texttt{C3k2 + C2PSA} 공간 어텐션 기반 \texttt{YOLO11m} (\texttt{231 layers /\allowbreak{} 20.\allowbreak{}06M params /\allowbreak{} 68.\allowbreak{}3 GFLOPs}) 채택.
\item Train split에 한정해 \texttt{Cyclist} / \texttt{Pedestrian} 포함 프레임을 가중 샘플링(\texttt{6,\allowbreak{}974} entries) 적용, \texttt{cos\_\allowbreak{}lr=True}, \texttt{mixup=0.\allowbreak{}1}, \texttt{close\_\allowbreak{}mosaic=10}, \texttt{patience=12} 설정으로 \textbf{\texttt{2$\times$ Tesla T4}}에서 DDP 학습 수행 (\texttt{24 epoch} 조기 종료, Best Checkpoint = \textbf{\texttt{Epoch 12}}, 약 108분 소요).
\item 추론 후단에 \texttt{mobile\_\allowbreak{}sam.\allowbreak{}pt} (\texttt{38.\allowbreak{}8 MB}) Box-Prompt 세그멘테이션을 결합하여 객체 마스크 및 지면 접지점(\texttt{mask\_\allowbreak{}bottom\_\allowbreak{}xy}) 추출.
\end{itemize}
\item \textbf{\texttt{v3} BEV 시각·오경보 개선 (\texttt{world\_\allowbreak{}model.\allowbreak{}py}, \texttt{world\_\allowbreak{}visualizer.\allowbreak{}py})}:
\begin{itemize}[leftmargin=1.5em,itemsep=2pt]
\item 오른쪽 BEV 패널에서 종방향 깊이 불확실성이 횡방향 차로와 타원을 2배 이상 왜곡·확대시키던 문제 수정(픽셀 야코비안 투영 $J=\text{diag}(s_x,-s_y)$, 횡방향 공분산 분리, 접근 속도 게이팅 \texttt{approach\_\allowbreak{}w}, 트랙별 EMA 스무딩).
\end{itemize}
\end{enumerate}

\section{5. ML Layer별 기술설명서 및 참고자료 (요약)}

전체 딥러닝·칼만·제어 레이어 명세 및 학술 문헌 목록은 별첨 기술설명서 \href{https://github.com/Heisnotanimposter/Totalcare\_autonomous\_driving\_Yolov5/blob/main/ML\_LAYER\_SPEC.md}{\texttt{ML\_\allowbreak{}LAYER\_\allowbreak{}SPEC.\allowbreak{}md}} 에 수록되어 있습니다.


\begin{enumerate}[leftmargin=1.8em,itemsep=2pt]
\item \textbf{\texttt{YOLO11m} (\texttt{231 layers}, \texttt{20.\allowbreak{}06M params}, \texttt{68.\allowbreak{}3 GFLOPs})}: Backbone (\texttt{Conv} Stem $\rightarrow$ \texttt{C3k2} CSP Bottleneck $\rightarrow$ \texttt{SPPF} $\rightarrow$ \texttt{C2PSA} Spatial Attention), Neck (\texttt{PAN-\allowbreak{}FPN}), Head (\texttt{Decoupled Anchor-\allowbreak{}Free Detect} + \texttt{DFL} + \texttt{CIoU} + \texttt{BCE}).
\item \textbf{\texttt{MobileSAM} (\texttt{38.\allowbreak{}8 MB})}: Knowledge-Distilled \texttt{TinyViT} Image Encoder (\texttt{MBConv} + \texttt{Windowed Self-\allowbreak{}Attention}), Box Prompt Positional Encoder, Two-Way Cross-Attention Mask Decoder + \texttt{4$\times$} Transposed Conv.
\item \textbf{\texttt{ByteTrack}}: 8D Constant-Velocity BBox Kalman Filter + 2단계 Hungarian Bipartite Matching (\texttt{High-\allowbreak{}Conf} + \texttt{Low-\allowbreak{}Conf} 가려짐 복구).
\item \textbf{Temporal World Model \& Safety Shield}: \texttt{P2} 역분산 깊이 융합 + OXTS \texttt{SE(2)} 보상 + 4D World-ENU 칼만 필터 + 야코비안 BEV 공분산 타원 투영 + $C^1$ 위험 포텐셜 \& \texttt{CollisionRiskSmoother} 슬루율/히스테리시스 평활화.
\item \textbf{\texttt{SegFormer-\allowbreak{}B2} (\texttt{nvidia/\allowbreak{}segformer-\allowbreak{}b2-\allowbreak{}finetuned-\allowbreak{}cityscapes-\allowbreak{}1024-\allowbreak{}1024}, v4 추가)}: MiT-B2 계층형 Mix-Transformer 인코더 + All-MLP 디코더 (\texttt{Non-\allowbreak{}Road} / \texttt{Other Road} / \texttt{Ego-\allowbreak{}Lane} 3-Class 헤드) + BEV IPM 역투영 및 HLS+Sobel 차선 2차 다항식 EMA 추적기.
\end{enumerate}
